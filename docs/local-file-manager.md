# 本地文件管理

## 已确认范围

- 所有平台：仅管理应用专属的 `Download/<应用标识>/`，默认进入 `games/`。不得回退到整个下载目录、任意用户目录或私有沙箱。
- HarmonyOS 通过 DOWNLOAD 模式解析根目录；其他平台单独适配目录授权，不能照搬鸿蒙 API。未获得指定目录权限时关闭文件操作。
- 用户已确认：其他平台允许首次通过系统选择器授权下载目录下的应用专属子目录，不允许选择任意位置扩大管理范围。
- 浏览、新建文件夹、多选、复制、移动、重命名；删除进入最近删除，永久删除另行确认。
- 压缩包解压到同名新目录，不覆盖已有文件、不删除源包。支持密码、进度和取消。
- 优先覆盖 ZIP、7z、RAR、tar 及 gzip/bzip2/xz/zstd 包装；常见分卷作为一组操作。
- 文件名完整保留 Unicode。UTF-8 为无标记名称的默认编码，旧 ZIP 可选 GB18030/CP932。
- 重命名、移动需保留游戏库、游玩记录及存档关联。游戏运行期间不执行管理任务。
- 复用现有菜单、弹窗、底部面板与玻璃控件，文件列表不使用玻璃背景。

## 操作规则

- 根目录、固定 `games` 容器及 `.krkr-manager` 工作目录不可重命名或移入回收站。
- 所有操作限制在管理根目录；拒绝链接、路径穿越、移动到自身子目录和静默覆盖。
- 任务临时文件与最近删除使用隔离目录，不参与游戏扫描。密码只存在内存中。
- 解压必须报告缺卷、错误密码、损坏、未知格式、编码错误和空间不足；不得以漏文件的方式成功。
- 最近删除保留到用户明确永久删除，不自动清空，不触碰私有存档。
- 平台与原生层仅返回稳定错误码及必要参数；Flutter 负责中文、英文、日文文案。未知错误码显示通用失败提示，不能直接展示底层异常或路径。
- 用户取消不作为故障弹窗；密码错误允许重试，授权失效要求重新授权。密码不写入日志、偏好或任务记录。

## 提交与验证顺序

1. 文件操作服务及安全/恢复测试。
2. 游戏路径、历史与存档稳定关联。
3. 独立归档接口、UTF-8/加密/分卷/异常样例测试。
4. 管理页与组件测试。
5. SDK 20 全量构建与真机验证，仅使用独立测试目录，不修改用户现有游戏。

文档依据：DevEco CLI《使用DOWNLOAD模式保存的文件如何访问》《应用文件访问(ArkTS)》
及 `DocumentPickerMode`（API 12 起）。系统 Archive 原生模块从 API 26 起，不作为 SDK 20 的依赖。
